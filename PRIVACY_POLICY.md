# PDF Editor Privacy Policy

Effective date: September 14, 2026

PDF Editor is designed to edit PDF documents locally on your Apple device. The
developer does not operate an application backend, analytics service, advertising
service, or user-account system for PDF Editor.

## Information PDF Editor handles

PDF Editor may handle the following information only to provide features that you
request:

- PDF documents and images that you open, import, edit, or export.
- Text recognized from document pages when you use on-device OCR.
- Document passwords while an encrypted document is open or while you prepare a
  password-protected copy.
- A PKCS#12 (`.p12` or `.pfx`) signing identity that you explicitly select for a
  digital-signing operation. PDF Editor imports it in memory for that operation
  and does not add it to the app's signature library.
- Handwritten signature templates that you choose to save. These remain in PDF
  Editor's local application-support storage until you delete them in the app or
  remove the app and its data.
- App preferences, such as which Tools sections are expanded, stored locally with
  Apple system preferences.
- On macOS, the system-managed recent-document list. You can clear it from PDF
  Editor's Recent files section or the File menu.

## Data collection, tracking, and sharing

PDF Editor does not send your documents, recognized text, passwords, signing
identities, signatures, preferences, or usage activity to the developer. It does
not use advertising identifiers, cross-app tracking, analytics, or telemetry, and
it does not sell personal information.

OCR uses Apple's on-device Vision framework. PDF rendering and editing use Apple
frameworks and a bundled PDFium library within the app.

## Files, iCloud, and third-party file providers

You choose files through Apple's document browser, file picker, or native open and
save panels. PDF Editor accesses only files and destinations that you select or
files stored in its own container.

If you choose iCloud Drive or another File Provider, that provider may store or
synchronize the file under its own terms and privacy policy. That processing is
performed by Apple or the provider, not by a server operated by the PDF Editor
developer.

## Retention and deletion

PDF Editor retains edited documents only at destinations you choose. Temporary
export files are removed after the related operation finishes or is cancelled.
Passwords and imported signing identities are not deliberately persisted by PDF
Editor.

You can delete documents using the Files app, Finder, or the relevant File
Provider. You can delete saved handwritten signatures inside PDF Editor and clear
the macOS recent-document list from the app. Removing PDF Editor and its data also
removes its locally stored preferences and signature library, subject to Apple's
and any File Provider's backup or synchronization behavior.

## Children's privacy

PDF Editor does not knowingly collect personal information from children or from
any other person.

## Changes to this policy

This policy may be updated when PDF Editor's features or data practices change.
The effective date above identifies the current version.
